Counting rules and data coverage

Unique cases count each procedure once across selected providers. Provider procedure counts sum each provider’s distinct cases: one shared case can contribute to more than one provider. Repeated codes, provider IDs and roles do not add extra counts for the same named provider.

Where an EXAMID is available, it identifies the case. Otherwise, MRN + exact exam timestamp + procedure type identifies a case. Provider names are uppercased and extra spaces removed; different spellings are not automatically merged.

Fellowship starts are inferred for the 24 apparent cohort members in the initial export. Review them with Edit fellowship years. Other names are unassigned. Activity outside the first three inferred years appears under “Other / unassigned.” Missing historical cohorts are shown as unavailable, not zero.

“Matched year to date” uses the export’s latest exam month, day and time as the same cutoff in every academic year. “Completed academic years” excludes the academic year containing the latest exam. An increase in volume can reflect more providers being represented, not just increased activity.

CSV imports run locally in your browser and replace the current dataset. Save dashboard to retain the new data in a self-contained HTML file. The saved dataset contains anonymous case numbers, timestamps, provider names and procedure types; it does not retain MRNs, codes or other patient identifiers. No external scripts or network services are used.
